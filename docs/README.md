# Документация Bot_Service

Разборы отдельных подсистем проекта — то, что не выводится из кода само собой:
почему сделано именно так и как это дорабатывать.

| Тема | О чём |
|---|---|
| [ai-assistant/](ai-assistant/) | ИИ-помощник на странице создания бота: панель, агентный цикл, инструменты, предложения настроек |
| [database/](database/) | БД: таблицы и связи, миграции alembic, изменение схемы, первый старт на сервере |
| [testing/](testing/) | Тесты бэкенда: запуск, структура, паттерны, рецепты написания новых |
| [stats/](stats/) | Статистика: главная и страница `/stats`, формулы метрик, мягкое удаление ботов |

Общее описание архитектуры проекта — в `CLAUDE.md` в корне репозитория.
